# Teniška akademija Breskvar — konceptni redizajn

Neuraden, sodoben redizajn spletne strani teniške akademije Breskvar (Ljubljana),
izdelan iz javno dostopnih informacij v predstavitvene namene. **Ni uradna stran akademije.**

- Statična stran: `index.html` + `styles.css` + `script.js` (brez build koraka, brez odvisnosti).
- Odziven, dostopen (semantični HTML, fokus stanja, `prefers-reduced-motion`), hiter.
- Paleta: globoka zelena igrišča + terakota + krem; Fraunces (naslovi) + Inter (besedilo).

Deploy: Render Static Site (publishPath `.`, brez build ukaza).

Viri vsebine: javno dostopne informacije (tenis-klub-breskvar.si, Teniška zveza Slovenije, javni mediji).
